Starlink Map

See your dish’s location on a live map using just your iPhone and your Starlink. No extra computer.

Before you start
  1. Join your Starlink Wi‑Fi on this iPhone.
  2. In the Starlink app: Settings → Advanced → Debug Data, turn on Allow access on local network (under Starlink Location).

That toggle can be missing on some newer hardware, and as of May 2026 many residential plans no longer expose location on the local API. Some Priority plans reportedly still do. This page cannot check your plan.

Recommended

Live map bookmark

A normal website is not allowed to read the dish’s location (the dish blocks other sites with CORS). The official dish page is allowed. This bookmark injects the map into that page so Safari can poll the dish every 10 seconds.

  1. Tap Copy bookmarklet.
  2. In Safari, bookmark any page (Share → Add Bookmark). Then open Bookmarks, tap Edit, open that bookmark, and paste the copied text into the URL / Address field. Name it Starlink Map.
  3. Open the dish page, then tap that bookmark.

The copied bookmark loads inject.js from this page’s own address, including a subpath such as /alt-maps/. Open the dish page http://192.168.100.1 (or http://dishy.starlink.com on some Starlink routers), then tap the bookmark. After the map appears you can also use Share → Add to Home Screen, but the icon will reopen the plain dish page — tap the bookmark again to bring the map back.

Home Screen

iOS Shortcut (one-tap snapshot)

Shortcuts can call the dish directly — they are not limited by Safari’s CORS rules. This gives you a location snapshot and opens this map. It is not a continuously updating live track; use Refresh (or the bookmark method) for a new fix.

  1. Open the Shortcuts app and create a new shortcut named Starlink Map.
  2. Add Base64 Decode. Set the text to this exact value (it is the get_location request):
AAAAAAPKPwA=
  1. Add Get Contents of URL.
    • URL: http://192.168.100.1:9201/SpaceX.API.Device.Device/Handle
    • Method: POST
    • Headers: Content-Type = application/grpc-web+proto and X-Grpc-Web = 1
    • Request Body: File — use the Base64 Decode result
  2. Add Base64 Encode on the contents of the URL.
  3. Add Open URLs, set to this page plus #grpc= and the encoded result. The URL looks like:

Then use Share → Add to Home Screen on this page, or add the Shortcut itself to your Home Screen. If the name isn’t exactly “Starlink Map”, the in-map Refresh button won’t find it.

Advanced

Try talking to the dish from this page

This is here so you can see what Safari does. On a typical public or HTTPS page it will fail, and that is expected. It may work only if this file is being served from the dish’s own origin.

Location is read from the dish over gRPC-web at 192.168.100.1:9201 (SpaceX.API.Device.Device/Handle, get_location). Map tiles are from OpenStreetMap and need an internet connection. This tool was not tested against a live dish from the machine that built it. It does not bypass the dish’s cross-origin protections.
